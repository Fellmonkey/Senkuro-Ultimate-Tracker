# Senkuro Ultimate Tracker

Расширение для Chrome, которое делает чтение на Senkuro удобнее: не даёт потерять прогресс, фармит карточки за тебя и помогает закрывать задания.

Работает в Chrome и Chromium-браузерах: Brave, Edge, Opera, Vivaldi, Яндекс.Браузер.

## Зачем это нужно

На Senkuro тайтлы лицензируют по-разному, и в обоих случаях ты рискуешь потерять прогресс:

- **Полное удаление** — страница тайтла исчезает. Без локальной копии ты не вспомнишь, на какой главе остановился.
- **Частичная блокировка** — страница остаётся, но главы недоступны. Читать негде, а прогресс висит в воздухе.

Расширение хранит копию твоей библиотеки прямо в браузере. Даже если сайт потеряет тайтл — твой прогресс останется.

## Что умеет

### 🎴 Фарм карточек
Сбор коллекционных карточек на страницах чтения — полностью автоматически.

- Включи фарм один раз — дальше он сам листает главы.
- Имитирует чтение: ждёт загрузки страницы, читает её сверху вниз со случайными паузами.
- Автоматически переключает читалку в горизонтальный режим — страницы не дублируются.
- Находит карточку, забирает её и закрывает модальное окно.
- Переходит к следующей главе сам.

*Небольшая просьба: используйте фарм по назначению — для экономии времени, а не для бесконечного «прогона» глав. Так будет спокойнее и вам, и сайту.*

### 📦 Архив удалённых тайтлов
Если тайтл удалён или заблокирован — он не пропадает.

- Тайтл остаётся в расширении с пометкой «Удалён».
- Номер последней главы и статус сохраняются.
- Вернулся на сайт? Расширение восстановит запись автоматически.

### ✅ Задания
Вкладка со всеми заданиями Senkuro.

- Список заданий: дедлайн, прогресс, статус, награды (опыт и очки).
- Сортировка: сначала то, что можно выполнить автоматически, затем — по ближайшему дедлайну.
- Автовыполнение для «Добавить в закладки» и «Оценить проект» — с мгновенной отменой, чтобы не оставлять следов в библиотеке и рейтингах.
- Статистика заработанных очков и опыта прямо в расширении.

## Начало работы

1. Открой `chrome://extensions` (или `edge://extensions`, `brave://extensions`).
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку проекта.
4. Иконка появится в панели инструментов.

### Быстрый старт

- **Синхронизация:** открой «Мои Закладки» на senkuro.com → иконка расширения → «Синхронизировать библиотеку» → «Сохранить данные».
- **Фарм:** открой главу манги → вкладка «Фарм» → включи тогл.
- **Задания:** вкладка «Задания» → «Авто: закладка» или «Авто: оценка».

## Технические детали

- Хранилище: `chrome.storage.local` (`senkuroProgress`, `senkuroFarmStats`, `senkuroTaskStats`).
- Синхронизация через GraphQL API Senkuro (`api.senkuro.com/graphql`, операция `userBookmarks`) — без DOM-скана и перезагрузок.
- Работает одинаково с `senkuro.com` и `senkuro.me`; авторизация по кукам, при необходимости — токен через `chrome.cookies`.
- Без сборки: чистый JavaScript + inline CSS, Manifest V3.
