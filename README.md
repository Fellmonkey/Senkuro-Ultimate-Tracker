# Senkuro Ultimate Tracker

Расширение для отслеживания прогресса чтения манги на senkuro.com / senkuro.me. Совместимо с Chrome и браузерами на его основе (Brave, Edge, Opera, Vivaldi, Яндекс.Браузер и др.).

## Проблема

На senkuro тайтлы лицензируют по-разному, и оба варианта — проблема:

**Полное удаление** — страница тайтла удаляется целиком. Если ты не помнишь, на какой главе остановился, прогресс теряется. Закладка ведёт в пустоту, и восстановить данные уже нельзя.

**Частичная блокировка** — страница остаётся, статус и прогресс на сайте сохранились, но главы недоступны для чтения. Ты видишь, что читал этот тайтл, но не можешь продолжить. Приходится искать другой сайт и вручную вспоминвать, где остановился.

В обоих случаях без локальной копии данных ты остаёшься без прогресса. Расширение решает это: сканирует закладки, сохраняет номер главы, статус и обложку в хранилище браузера. Даже если тайтл заблокирован или удалён — прогресс остаётся в базе. Удалённые со страницы тайтлы помечаются как «Удалён» и не удаляются из плагина — ты всегда знаешь, на какой главе остановился, и можешь продолжить на другом сайте.

## Что делает

- Сканирует закладки («Читаю», «В планах», «Прочитано») и сохраняет данные локально
- Определяет лицензионные тайтлы и показывает их отдельно
- Сохраняет удалённые со страницы тайтлы («мертвые души») — прогресс не теряется
- Показывает статистику: количество тайтлов, глав, любимый формат
- Ручное редактирование глав для лицензированных тайтлов
- **Автофарм карточек** — автоматический сбор коллекционных карточек на страницах чтения

## Установка (разработка)

1. Откройте `chrome://extensions` (или `edge://extensions`, `brave://extensions` и т.д.)
2. Включите «Режим разработчика»
3. Нажмите «Загрузить распакованное расширение» и выберите папку с этим проектом
4. Иконка расширения появится в панели инструментов

## Использование

### Синхронизация закладок

1. Откройте страницу «Мои Закладки» на senkuro.com
2. Нажмите на иконку расширения
3. Нажмите «Синхронизировать библиотеку»
4. Подтвердите начало сканирования (страница будет перезагружена)
5. Просмотрите отчет об изменениях и нажмите «Сохранить данные»

### Просмотр тайтлов

- **Читаю / В планах / Прочитано** — фильтрация по статусу чтения
- **Лицензии** — тайтлы, заблокированные по лицензии (их нельзя читать через сайт)
- **Статистика** — сводка по всему прогрессу

### Редактирование глав

- Для лицензированных тайтлов можно вручную ввести номер главы (поле редактируется)
- Для обычных тайтлов номер главы заполняется автоматически и не редактируется

### Удаление тайтла

Наведите курсор на карточку и нажмите «✖» в правом верхнем углу.

### Автофарм карточек

1. Откройте страницу чтения главы манги на senkuro (URL вида `/manga/{slug}/chapters/{id}/pages/{num}`)
2. Откройте popup → вкладка **Фарм**
3. Настройте **задержку** (секунды между попытками) и **попыток на страницу**
4. Включите тогл
5. Фарм пролистывает все страницы главы, на каждой проверяет наличие карточки (`img.cards-drop`)
6. Если карточка найдена — кликает, забирает её, закрывает модальное окно
7. После последней страницы автоматически переходит к следующей главе
8. Повторяет пока есть главы или пока не выключите тогл

**Важно:** фарм работает только на страницах чтения глав. На странице закладок или информации о тайтле — не запустится.

## Структура проекта

```
├── manifest.json    — конфигурация расширения (MV3)
├── senkuro-api.js  — слой GraphQL API Senkuro (закладки через userBookmarks)
├── content.js       — скрипт страницы: сканирование, проверка лицензий, фарм карточек, запросы к API
├── popup.js         — логика popup-окна: сетка, статистика, синхронизация, управление фармом
└── popup.html       — разметка popup с инлайн-стилями
```

## Технические детали

- Данные хранятся в `chrome.storage.local` под ключом `senkuroProgress`
- Структура записи: `{ slug, title, lastChapter, isLicensed, userStatus, format, coverUrl, globalStatus, date }`
- Лицензии определяются запросом `/manga/{id}/chapters` и поиском ключевых слов об удалении
- При синхронизации расширение запрашивает **GraphQL API** `api.senkuro.com/graphql` (операция `userBookmarks`): закладки приходят целиком, курсорной пагинацией, вместе со статусом вкладки, прогрессом чтения и флагом лицензии `isLicensed`. Старый DOM-скан с прокруткой страницы и проверкой лицензий через HTML удалён — API заменяет их полностью.
- API работает одинаково для `senkuro.com` и `senkuro.me` (это один сайт); токен сессии ищется на обоих доменах, ссылки на карточках ведут на тот домен, что открыт во вкладке.
- API запрашивается из контентного скрипта со страницы Senkuro (`credentials: 'include'`); если сессия живёт в host-only куке, токен `access_token` читается через `chrome.cookies` и передаётся как `Authorization: Bearer`.
- Автофарм умеет закрывать новое окно «Получена новая карта!» (клик по «Нажми, чтобы продолжить» или по фону), а не только старое `.modal-container-drop`.
